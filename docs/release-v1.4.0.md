# Candidate Check v1.4.0 — каталог вопросов и demo-аналитика

## Результат

Администратор получил отдельный каталог всех вопросов с поиском, фильтрами и полным lifecycle. Из интерфейса можно создать вопрос, изменить категорию, сложность, формулировку и 2–6 вариантов ответа, выпустив новую immutable-редакцию. Для проверки аналитики локальная D1 может быть воспроизводимо заполнена 50 синтетическими кандидатами.

## Основные изменения

- верхнеуровневая вкладка «Банк вопросов» и совместимые deep links из аналитики;
- поиск по ID, категории, тексту, контексту, вариантам и `dedupeKey`;
- фильтры по категории, сложности, lifecycle и области редакций;
- стабильная сортировка и cursor pagination, привязанные к ревизии банка и фильтрам;
- явные статусы `active`, `archived`, `superseded`;
- создание и редактирование новой редакцией с 2–6 вариантами ответа;
- безопасная архивация и восстановление без физического удаления historical rows;
- 50 детерминированных demo-кандидатов с exact-facts ledger и готовыми analytics aggregates;
- точечная очистка demo-namespace и гарантия отсутствия Telegram outbox.

## Совместимость и данные

- новая миграция не требуется: используются существующие immutable question rows, revision membership и analytics tables;
- старые вопросы, попытки и ответы не пересчитываются и не удаляются;
- изменение canonical content создаёт successor с новым ID;
- предыдущая редакция остаётся доступной в истории и не участвует в новых тестах;
- demo-seed сохраняет реальные локальные попытки и при повторе заменяет только свои обезличенные строки.

## Проверки релиза

- unit/API: parsing фильтров, lifecycle, cursor consistency, отсутствие физического удаления;
- seed integration: 50 кандидатов, exact identity, base/remedial ledger, scoring и analytics rebuild;
- WebKit: iPad portrait/landscape, каталог, редактор, create/revise/archive/restore;
- полный `npm run verify`, включая secrets, банк, unit/integration, ops, build, E2E и audit.

## Откат

Код можно вернуть после остановки приложения. Demo-данные удаляются командой `npm run db:demo:clear`. Изменения банка откатываются только восстановлением проверенного logical backup или новой immutable-редакцией; удалять question rows и revision membership вручную нельзя.
