# Candidate Check v1.4.1 — совместимость административного PIN

Патч-релиз сохраняет функциональность v1.4.0 и разрешает локальный административный PIN длиной 4–12 цифр во всех слоях: Node-конфигурации, серверной проверке и форме входа.

Исходный PIN по-прежнему читается только Node-обёрткой из игнорируемого Git файла `admin_pin.txt`. Worker получает PBKDF2-SHA256 hash/salt и отдельный случайный session secret; PIN не попадает в D1, клиентский bundle или журналы.

Проверка релиза: `npm run verify`.
