# Candidate Check v1.6.1

Патч-релиз устраняет две UI-регрессии релиза `v1.6.0` без изменения API, схемы данных
и scoring.

## Исправлено

- маскот стартового экрана помещён за карточку, поэтому на планшетной и узкой desktop-ширине
  он больше не перекрывает заголовок «Начало теста»;
- в шапку ИБ-челленджа добавлена явная кнопка «← Назад» с возвратом на главную;
- для кнопки предусмотрены focus-visible, hover и компактное отображение шапки на телефоне.

## Проверка

- typecheck, lint и production build;
- визуальная проверка стартового экрана на desktop и iPad-ширине;
- проверка кнопки возврата и маршрута `/candidate/` в опубликованной версии.

## Откат

Повторно развернуть commit релиза `v1.6.0`. Миграция базы данных не требуется.
