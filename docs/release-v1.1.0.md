# Candidate Check v1.1.0

## Результат

Релиз делает раздел «Качество вопросов» понятным администратору, не ослабляя exact-аналитику и статистические ограничения v1.0.0.

Основное изменение: наблюдаемые факты больше не скрываются из-за малой выборки. Sample gates управляют только допустимой уверенностью вывода, quality status и рекомендацией.

## Scope

- абсолютные счётчики и доли с числителем/знаменателем при любом `n`;
- уровни достоверности `Мало данных / Первичный сигнал / Рабочая оценка / Стабильная оценка`;
- явные `nextGate` и число результатов до следующего уровня;
- запрет рекомендации `Оставить без изменений` при `n < 50`;
- отдельные объяснимые сигналы сложности, тайм-аутов, времени и discrimination;
- индекс качества в формате `earned / maxAvailable` без скрытой нормализации partial score;
- серверный поиск по ID, теме, сложности и полному тексту вопроса;
- серверная сортировка до пагинации и приоритет проблемных вопросов по умолчанию;
- `totalCount` по отфильтрованному набору и summary распределения статусов;
- компактная шестиколоночная таблица в landscape и карточное представление на iPad portrait;
- переработанный detail: диагноз → достоверность → факты → quality → варианты → действие → ручное решение.

## Контракт совместимости

- `QUESTION_ANALYTICS_MODEL_VERSION = 2` явно маркирует новый question analytics payload;
- legacy-поля question item временно сохраняются для совместимости экспортов и соседних экранов;
- identity exact cohort, raw ledger, scoring, verdict, candidate flow и Telegram не меняются;
- миграция D1 не требуется: релиз меняет derived/API/UI-представление существующих exact facts;
- ключи ответов, тексты вариантов и raw-ответы кандидатов не добавляются в list API.

## Rollout

1. Убедиться, что предыдущий `npm run verify` зелёный и рабочее дерево ожидаемо.
2. Запустить полный `npm run verify` для v1.1.0.
3. Перезапустить локальный dev-сервер, чтобы release metadata и bundle обновились.
4. Войти через `/admin/login` и проверить вкладку «Вопросы» в portrait/landscape.
5. Проверить поиск по ID и фрагменту текста, сортировку, пагинацию и detail одного вопроса.

Публикация во внешнюю среду в scope релиза не входит.

## Rollback

Изменение не требует отката данных. Для rollback достаточно вернуть приложение на предыдущий commit/tag v1.0.0 и перезапустить локальный runtime. Exact facts и persisted aggregates совместимы; destructive SQL не выполнять.

## Проверки

```powershell
npm run test:analytics
npm run typecheck
npm run lint
npm run test:e2e -- --grep "admin analytics"
npm run verify
```

Ключевые regression cases:

- границы `29/30/49/50/99/100`;
- `keep` недоступен при `n < 50`;
- expected difficulty boundaries включительны;
- timeout `25%`, distractor `5%` и slow `1.5×` обрабатываются на точных границах;
- partial quality не нормализуется до 100;
- search/sort применяются до pagination;
- `totalCount`, summary и cursor согласованы;
- UI не создаёт горизонтальный scroll в WebKit iPad portrait/landscape.

Подробная семантика метрик: [`analytics-metrics.md`](analytics-metrics.md).
